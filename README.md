## 记号与阅读约定

- `b` 表示 bit，`B` 表示 Byte，$1\,\mathrm{B}=8\,\mathrm{b}$。
- 网络传输速率通常按十进制换算：$1\,\mathrm{Mbps}=10^6\,\mathrm{bit/s}$。
- 公式使用 GitHub 可显示的 LaTeX；流程和层次关系优先用 Mermaid 表示。
- 课件原图只保留对理解协议、报文或系统结构确有帮助的部分，路径均为仓库内相对路径。
- 带年代、规模、市场份额或部署数量的数据是课件给出的历史快照，不应当作实时统计。
